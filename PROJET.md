# Projet : rika-firenet-openfirenet-dev

## Contexte & Objectif
Adaptation et évolution du custom component Home Assistant `rika_firenet` pour supporter nativement le firmware alternatif OpenFirenet en local / MQTT / API locale en remplacement ou complément du cloud propriétaire Rika Firenet.

## Emplacement
`/home/temps-perdu/projets/rika-firenet-openfirenet-dev`

## Architecture & Composants
- `custom_components/rika_firenet` : composant d'intégration Home Assistant.
- `HA config` : configurations lovelace et automatisations de référence.
- `test_openfirenet_compat.py` : suite de tests de compatibilité OpenFirenet.
